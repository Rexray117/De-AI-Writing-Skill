# 词表与模型指纹

三级分法的逻辑：**A 级删掉不损失信息，B 级有真实功能但要限量，C 级是文体义务不能删。**

判级不看词本身，看它在这句里干了什么。

---

## A 级 · 必删（删掉不损失信息）

### 空转名词

赋能、闭环、抓手、落盘、底座、生态位、护城河、心智、颗粒度、组合拳、卡点、串联、打通、复用、沉淀、对齐、拉通、矩阵、玩法、势能

### 结构连接（串场词）

综上所述、总而言之、总的来看、值得注意的是、更重要的是、更有意思的是、首先/其次/最后（三段式连用）、换句话说（重复解释型）、与此同时（无时间关系时）

### 空断言

本质上、归根结底、不难发现、众所周知、显而易见、毫无疑问、可以说

### 抬价副词

极其、极度、完美、彻底、全方位、深层次、真正意义上、最大限度地

### 处理方式

命中不等于必改。判据是：把这个词换成更朴素的同义表达，句子还成立吗？

- 「赋能业务」→ 换成「帮业务做 X」，句子塌了 → 说明这个词在替一句空话打掩护，整句删。
- 「实现闭环」→ 换成「做完这步回到第一步」，句子仍成立 → 那就换掉。

## B 级 · 慎用（有真实功能，全篇上限一次）

| 项 | 什么时候算有用 | 什么时候算废话 |
|---|---|---|
| 「不是 X，而是 Y」 | 真的有人主张过 X，需要现场驳 | 只为抬高 Y，X 是模型自己立的稻草人 |
| 破折号「——」 | 补一个必须的限定 | 一句里塞两次解释 |
| 括号补充 | 给出版本、单位、来源 | 此地无银式标注，如「（无红烧肉版）」 |
| 列表化 | 条目并列且互不依赖 | 该讲因果的地方给 bullet |
| 「这意味着」 | 推出一个不显然的结论 | 把上一句换个说法 |
| 每节小结 | 长篇报告的分章收束 | 三段小文也要收束 |
| 比喻 | 解释一个真的难懂的东西 | 每段一个，纯装饰 |
| 加粗 | 关键词首次出现、需要扫读定位 | 每段首句加粗、整段加粗 |

## C 级 · 看文体保留

- **合规／医疗／法律**：免责与条件限定是义务。保留，但写成条件句、集中放「适用范围」，不要每段撒。
- **学术**：hedge 是学术诚实，不是 AI 腔。判据同上——限定是否对应真实的不确定性。
- **公文**：公文有自己的套话语体，「可 XX」「建立 XX 机制」未必来自 AI。改公文别拿这把刀。
- **申论/应试**：三段式与并列结构是评分标准的一部分，不适用本表。

## 模型指纹（作线索，不作结论）

同一个句式在不同模型上的浓度差异很大。命中指纹就提高警惕，但别拿模型名当判决——评论区里说 Gemini「唯一说人话」的拿 358 赞，说它「味最大」的也在热评里。

| 模型 | 典型句 | 常见触发场景 |
|---|---|---|
| GPT | 「不能宣称」「不能说明」「这不代表」；开头先「对，……」再转折 | 分析结论、效果评估，一律不粘锅 |
| GPT | 「如果你讨论在 X 条件下、Y 时间段内、Z 的层面上，A 确实可以说是第一」 | 任何比较级问题 |
| GPT | 先反驳用户，再说「在什么情况下你是对的」 | 陈述既定事实时 |
| Claude | 短剧腔：「指尖泛白」「心跳漏了一拍」「溺水之人抓住浮木」「……才能立住」 | 叙事、产品文案、剧情 |
| Claude | 括号补充与安抚：「主动权始终在你，随时可以编辑内容」 | 界面、注释、说明书 |
| Claude | 「这一笔我记住了」「我认」「接住了」 | 共情式回应 |
| DeepSeek | 三连否定：「不吵、不嚷、不骂」 | 论述、剧情 |
| DeepSeek | 单字动词顶替双字：「收」代「收拢」、「立」代「立住」 | 抽象论述 |
| DeepSeek | 古龙味短句 + 电影感调度 | 角色扮演、故事 |
| Gemini | 「极其极其极其」；单向吹捧用户 | 一切对话 |
| 通用 | 「更有意思的是」「这是一个很好的问题」「瞬间」「令人不安」 | 转场、开场白 |

## 诊断指标（人工估算，不作判决）

`scan.py` 只算词面与章节密度。想进一步定位"哪里最平"，用下面五项估一下，三分钟够用：

| 指标 | 怎么估 | 参考线 | 说明 |
|---|---|---|---|
| 句长方差 | 看连续五句的字数，最大与最小差多少 | 差 <10 字算平 | 平不等于错，说明节奏单调 |
| 显性逻辑词密度 | 数「因此/然而/此外/首先/最后」，除以千字数 | >8 处/千字偏密 | 明线太多，读者被牵着走 |
| 介词框架开头 | 数以「在…下 / 通过… / 基于…」开头的句子占比 | >30% | 官腔模板区 |
| 虚词密度 | 「的/了/着/过」占全文比例 | >8% | 多半是长定语链 |
| 僵尸词 | 同一实词在 200 字内出现几次 | ≥3 次 | 词汇贫乏，换说法或换角度 |

这几项是校准提示，不是评分。检测器不认它们，读者也不认——它们只帮你找到最该动手的那一段。

## 从零代写时的提示词块

```text
写作禁令：
1. 同一对象不并列三个以上定语，不用「可A可B可C」。
2. 不写「不是…而是…」「不只是…更是…」的否定递进。
3. 不给简单操作补动机、画面、情绪。
4. 免责只写一次，写成条件句，放文末。
5. 不用「一次…到处…」「一个…多个…」的对仗口号。
6. 不写「主动权始终在你」「随时可以撤销」这类安抚。
7. 每节不写总结句，不写「总之」「值得注意的是」。
8. 不用破折号与括号做二次解释。
自检：任删一句，信息是否有损？无损即删。
```
