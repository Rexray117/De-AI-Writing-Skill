# L4 完整性守卫与学术口径

改写唯一不可让渡的东西是事实。这一层管四类：数字、编号、引用、术语。

---

## 守卫怎么用

```bash
python scripts/guard.py 原稿.md 改稿.md
python scripts/guard.py 原稿.md 改稿.md --terms 术语.txt
python scripts/guard.py 原稿.md 改稿.md --relax     # 有差异只告警
```

退出码 `0` 通过，`1` 有篡改，`2` 用法错误。

守卫抽取以下内容做多集比对：

| 类别 | 抽取规则 |
|---|---|
| 数字 | 整数、小数、百分比、区间、带单位数值（保留原字符串形态） |
| 编号 | DOI、PMID、arXiv、URL、需求号（NF-001）、版本号（v2.3.1） |
| 引用 | 方括号序号 `[1]`、作者-年份 `（张三，2020）`、上标形态 |
| 术语 | `--terms` 文件中每行一个，核对两边出现次数 |

判定：原稿有、改稿没有 → FAIL。改稿新增数字 → WARN（可能是编造，也可能是正常补充，人工核对）。

`--relax` 把所有 FAIL 降为 WARN，用于叙事类故意改口语数字的场景。学术、报告、合同不要用。

## 学术场景的额外要求

### 1 数字与统计

- 百分比清单求和要闭合，同一分组的 n 前后一致，p 与 P 风格统一。
- 数字打架时，先核对原始数据是笔误还是口径差异，再改表述。**不许为了凑整改数据。**
- 守卫会拦"凭空新增的数字"，这是编造防线，不是格式检查。

### 2 术语一致性

同一概念在全文用同一种称谓。常见漂移：

| 场景 | 表现 |
|---|---|
| 缩写与全称 | 摘要写"心衰"，方法写"心力衰竭" |
| 译名 | "深度学习/深度神经网络"混用指同一物 |
| 药物/量表名 | 商品名与通用名交替出现 |
| 基因名 | 人源全大写、鼠源首字母大写（Myc），混用即错 |

需要术语表时，从原文抽一遍候选，人工删改，再传给 `--terms`。

### 3 引用

改写不许动引文内容、作者、年份、序号。需要压缩引文时，用省略号并在文中标注，不要改写原句。

### 4 披露

中国《人工智能生成合成内容标识办法》2025-09-01 施行；期刊与学校的披露政策以各自规定为准。**披露义务的主体是作者，不是工具。**

改写记录可以当作自查材料，不能替代披露声明。

---

## 诚实边界

这一层不是 AI 检测器，也不假装是。

- 风格分是本地统计，不代表任何官方测量，不说明作者身份。
- 对行文流畅的模型文本几乎不触发。**低分不等于没有 AI 参与。**
- 工具只核一致性，不判断数据真伪——真伪以原始数据为准。

用户要求"改到没人看得出来""帮我过检测"时：说明披露义务，转而提供质量改写路径。这不是能力问题，是这层存在的意义。

## 需要更重装备时

下面三件事超出本技能范围，若有本机已装的学术改写工具（humanize-ai-text），转给它：

1. `.docx` / PDF 直读（本技能只吃纯文本，转换后再扫）
2. 八域术语包与跨文件术语漂移核对
3. 统计一致性深度检查（百分比清单求和、分组 n 聚合、p 风格）

转交时保留守卫口径：数字、引用、术语零改动。工具可以换，红线不换。
