# 改写案例库

改的时候照着找同类，比抽象记规则快。每条给：病句、改后、动的是哪一刀。

---

## PRD／技术文档

**1 堆叠定语 + 小剧场**

> 本模块提供可配置、可追溯、可回滚的风险等级阈值管理能力，当用户进入配置页时，系统会立即加载当前生效的阈值，让用户无需等待即可开始调整。

改：阈值在配置页直接改，改动留痕，可一键回滚。加载走本地缓存，首屏 300ms 内可编辑。

刀：拆定语成事实 + 补数字。

**2 防御性 + 吃定心丸**

> 需要注意的是，本次只调整阈值配置，不是重做整个风险模型，你始终掌握主动权，可随时撤销修改。

改：本次只动阈值配置，模型结构不变。修改可在「配置历史」里撤销。

刀：删否定 + 安抚换入口。

**3 小剧场（字段说明）**

> 提交按钮：点击后系统会校验所有必填项，如果填写完整就会立即提交，让用户感受到流畅的操作体验。

改：提交按钮：校验必填项，通过后提交；缺项时定位到第一个空字段。

刀：三段式还原。

## 调研报告

**4 对仗口号 + 段末总结**

> 平台一次接入，多端复用，真正实现了数据价值的全面释放。综上所述，该方案具备显著的推广价值。

改：平台接入一次，PC、移动端、大屏三端共用同一套数据源。目前已在两个项目落地，第三个项目在接入中。

刀：口号拆成事实 + 删总结 + 补证据。

**5 否定递进**

> 这不仅是一份跑分对比，更是一次对手机性能天花板的重新定义。

改：跑分对比覆盖 12 款机型，连续三轮测试，取中位数。

刀：删递进，换可验证描述。

## 简历

**6 堆叠定语**

> 负责智能化、可视化、可扩展的气象风险系统的全流程设计与落地，具备优秀的跨团队协作能力与业务洞察力。

改：主导风险等级模块：把风速、温度、湿度、气压四类因子映射为四级风险，前端用 Leaflet + ECharts 出图，后端接口 8 个。上线后在 3 个项目中复用。

刀：定语换动作与数量 + 删自我评价。

**7 吃定心丸式自评**

> 学习能力强，能快速适应新环境，善于沟通，具有良好的团队精神。

改：（删整段）

刀：无信息量的段落直接删，不留替代。

## 邮件／IM

**8 过度免责 + 安抚**

> 请注意，以下内容仅代表个人理解，不代表团队最终意见，如有偏差敬请谅解，也欢迎随时沟通。

改：以下是我理解的方案，周四评审前有异议可以直接在文档里标注。

刀：免责压成一句 + 给具体动作。

**9 客套开场**

> 你好！希望这封邮件能找到你。首先感谢你抽出宝贵时间阅读，我想就上周提到的排期问题与你做一些沟通。

改：上周提到的排期，有两个点需要定：验收时间、联调窗口。

刀：删客套 + 结论前置。

## 小说／剧情

**10 AI 短剧腔**

> 他指尖泛白，心跳漏了一拍。命运的齿轮开始转动，他知道，这一刀，他记住了。

改：他捏着杯沿，指节压得发白，杯子在桌上磕了一下。他没接话，把烟按进烟灰缸，起身走了。

刀：抽象情绪换具体动作 + 删宿命句式。

**11 情绪通胀**

> 两人对视，空气瞬间凝固，仿佛一场无声的战争在这间小屋里爆发。

改：两人都没说话。她把碗往桌上一放，汤溅出来一点。

刀：把"仿佛"删掉，让动作承担张力。

## 产品／公众号文案

**12 数字排比**

> 一台设备，两种模式，三重保障，四季无忧。

改：设备支持室内和户外两种模式。防水做到 IP67，零下 20 度能开机。

刀：口号拆成参数。

**13 堆叠卖点**

> 全新升级的智能算法，带来更精准、更高效、更懂你的使用体验。

改：识别准确率从 82% 提到 94%，误报减少一半。

刀：形容词换指标。

## 通用句式替换表

| 病句 | 改法 |
|---|---|
| 让用户无需等待 | 200ms 内返回 |
| 真正懂你 | 记住上次的选择 |
| 一次配置，全流程生效 | 后台配一次，PC 与移动端同时生效 |
| 主动权始终在你 | 右上角可撤销，30 天内可恢复 |
| 不只是功能，更是体系 | （删，或写清它到底解决了谁的什么问题） |
| 不能代表真实表现 | 适用于 mock 数据，真实条件待验证 |
| 旨在为用户提供… | （删「旨在」，写它做什么） |
| 极大提升了效率 | 从 4 小时压到 20 分钟 |
